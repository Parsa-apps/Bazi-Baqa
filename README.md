# بازی بقا | Parsa Apps

یک نمونه‌ی قابل‌بازی از بازی راهبردی ـ بقای فارسی برای Android؛ گروهی از بازماندگان باید با همکاری، جمع‌آوری منابع، ساخت پایگاه و دفاع شبانه زنده بمانند.

**سازنده:** Parsa Apps  
**مدیریت:** فرشاد پارسا  
**وب‌سایت:** https://Parsa-apps.github.io

## وضعیت

- موتور: Unity 2022.3 LTS یا جدیدتر
- هدف: Android
- زبان رابط: فارسی و راست‌چین
- صحنه‌ی اصلی: `Assets/Scenes/Main.unity`
- راهنمای معماری: `Docs/Architecture.md`
- راهنمای خروجی Android: `Docs/AndroidBuild.md`

## اجرای پروژه

1. پروژه را با Unity باز کنید و اجازه دهید Assetها Import شوند.
2. صحنه‌ی `Assets/Scenes/Main.unity` را باز کنید.
3. دکمه‌ی Play را بزنید.
4. برای شروع، «آغاز نجات» را انتخاب کنید؛ برای لمس گوشی، ساخت‌وساز از نوار پایین انجام می‌شود.

## بازی نمونه

چوب، سنگ، غذا، آب و انرژی جمع کنید؛ پناهگاه، مزرعه و برج دیده‌بانی بسازید؛ نیازهای گروه را مدیریت کنید و تا روز هفتم در برابر حمله‌های شبانه دوام بیاورید.

این نسخه بدون Asset خارجی، با Primitive و افکت‌های رویه‌ای اجرا می‌شود تا پروژه در اولین باز شدن Unity خطای Missing Reference نداشته باشد. پوشه‌های `Prefabs`، `Materials`، `Textures` و `Audio` برای جایگزینی تدریجی Assetهای نهایی آماده هستند.
